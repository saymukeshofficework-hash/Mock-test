# Ludo 3D

A premium, fully client-side 3D Ludo game for the web — built with **Three.js** and **Vite**. Real 3D board, tokens, and dice; smooth animations; local pass-and-play for 2–4 players; no backend, no accounts, works entirely offline once loaded.

> The Classic Game. Reimagined.

## Features

- **Genuine 3D presentation** — a raised wooden platform, a cross-shaped Ludo board with colored bases, safe-cell markers, and a four-wedge center home, all built from real Three.js geometry (not a flat image).
- **3D tokens** with a small base, tapered stem, and rounded head; they hop cell-by-cell with an easing bounce, glow and float when they're a legal move, and lift-spin-shrink back to base when captured.
- **A real rolling die** — the face you see is generated by physically-plausible tumble + bounce animation that always lands on the number the (independently random) game logic already rolled.
- **Accurate Ludo rules**: 2–4 players, roll-a-6-to-leave-base, bonus rolls on 6, exact-landing to finish, capturing on non-safe cells, safe/star cells, and win detection — implemented as small, pure, testable functions (`src/game/Rules.js`) completely decoupled from rendering.
- **Full local pass-and-play UI**: start screen, player setup (2/3/4 players, name validation), in-game HUD with four player panels, turn indicator, legal-move highlighting, in-game menu, settings, how-to-play, and a confetti winner screen.
- **Settings** for sound, music, animation quality (auto-reduces shadows/effects on weaker devices), camera auto-rotate, and fullscreen — all persisted to `localStorage`.
- **Save / Continue** — the current match state is saved to `localStorage` after every turn; a corrupted or missing save is handled gracefully.
- **Sound** synthesized live with the Web Audio API (dice, moves, captures, home, clicks, turn changes, victory fanfare, and a soft ambient pad) — no external audio files, so there's nothing to license.
- **Responsive & accessible** — real breakpoints from 320px phones to 1440px desktops, large touch targets, keyboard-focusable controls, `aria-live` status updates, and full `prefers-reduced-motion` support.
- **Graceful degradation** — a friendly fallback screen if WebGL isn't available, and automatic quality scaling for low-end devices.

## Gameplay

1. From the start screen, choose **PLAY GAME**.
2. Pick 2, 3, or 4 players and give each a name.
3. Players take turns tapping **ROLL DICE**. A **6** is required to bring a token out of your base, and always earns another roll.
4. When more than one token can legally move, the eligible tokens glow — tap one to move it exactly the number rolled.
5. Landing on an opponent's token sends it back to their base, unless it's sitting on a starred safe cell.
6. Bring all four tokens home before everyone else to win!

## Technologies

- [Three.js](https://threejs.org/) — 3D scene, geometry, materials, lighting, shadows, `OrbitControls`
- [Vite](https://vitejs.dev/) — dev server & production build
- Vanilla JavaScript (ES modules), HTML5, CSS3 — no UI framework, no runtime dependencies beyond Three.js
- Web Audio API — synthesized sound effects & music (no external audio assets)
- `localStorage` — settings and save-game persistence

## Installation

```bash
cd ludo-3d
npm install
```

## Development

```bash
npm run dev
```

Opens a local dev server (default `http://localhost:5173`) with hot module reload.

## Production Build

```bash
npm run build
```

Outputs a static, deployable site to `ludo-3d/dist`. Preview it locally with:

```bash
npm run preview
```

## GitHub Pages Deployment

The build uses a **relative base path** (`base: './'` in `vite.config.js`), so the same build works whether it's hosted at your domain root or at `https://USERNAME.github.io/REPOSITORY/` — no repo-name hard-coding required.

### Option A — GitHub Actions (included)

This repo ships `.github/workflows/deploy.yml`, which builds `ludo-3d/` and deploys it to GitHub Pages automatically on every push to `main` that touches the `ludo-3d/` folder.

1. In your repository, go to **Settings → Pages** and set **Source** to **GitHub Actions**.
2. Push to `main`. The workflow builds the project and publishes `ludo-3d/dist` to Pages.
3. Your game will be live at `https://USERNAME.github.io/REPOSITORY/`.

### Option B — Manual

```bash
cd ludo-3d
npm install
npm run build
# then publish the contents of ludo-3d/dist to your gh-pages branch
# (e.g. with the `gh-pages` npm package, or by copying dist/ into a gh-pages branch)
```

## Known Limitations

- This is a **local pass-and-play** game only (everyone plays on one device, taking turns); there is no online/networked multiplayer.
- There is no computer/AI opponent — all seats are human-controlled.
- The save system keeps a single most-recent match; it isn't a multi-slot save system.
