# MPESB Group-4 Assistant Grade-3 — Test Series Blueprint

Status: syllabus blueprint only. This directory is not yet a publishable test series.

## Pattern (based on the MPESB Group-4 2024 rulebook)
- One objective paper
- 100 questions, 100 marks
- Duration: 2 hours
- Four options per question
- Subjects: General Knowledge, General Hindi, General English, General Mathematics, General Computer Knowledge, General Aptitude

The 2024 rulebook specifies the six subjects and overall paper structure; it does not prescribe a fixed subject-wise question allocation. The practice series must therefore use a balanced distribution without presenting it as an official allocation.

## Planned content
- 25 separate mock tests
- 100 questions per test (2,500 total)
- Hindi and English question/option text
- Four options per question and one verified correct answer
- No repeated questions across tests
- No answer hints or revealing explanations

## Publication gate
Do not expose this course as an active test series until all 25 question files are complete, validated for duplicate questions and answer-key integrity, and connected to the mock-test engine.
