# Mock Tests

Standalone HTML mock exam files, generated by the `test-generator-agent` skill (see `.claude/skills/test-generator-agent/`).

- `templates/` — master HTML templates (UI/UX + app logic). Never edit these to change question content; they're cloned, not modified in place.
- `output/` — generated tests, one self-contained `.html` file per test. Open directly in a browser.
