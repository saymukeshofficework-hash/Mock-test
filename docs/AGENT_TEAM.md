# TETTESTHUB एजेंट टीम

यह टीम Claude Code में `.claude/agents/` के तहत उपलब्ध है। हर एजेंट असली फ़ाइलें पढ़कर रिपोर्ट देता है; बदलाव मुख्य सत्र में मालिक की मंज़ूरी के बाद ही होते हैं। (Claude पर भी इन्हीं 12 पात्रों का साझा ग्रुप-चैट पेज है, मालिक और CEO उसमें विचार-विमर्श करते हैं।)

| एजेंट | नाम | काम |
|---|---|---|
| `tt-manager` | विक्रम | मैनेजर (व्यापार टीम लीड) |
| `tt-inspector` | नेहा | इंस्पेक्शन व क्वालिटी |
| `tt-marketing` | रिया | मार्केटिंग व जागरूकता |
| `tt-selling` | अर्जुन | सेल्स व प्राइसिंग |
| `tt-performance` | समीर | परफ़ॉर्मेंस व कैलेंडर |
| `tt-techlead` | राहुल | टेक लीड |
| `tt-frontend` | आर्यन | फ्रंटएंड व मोबाइल UI |
| `tt-backend` | दीपक | बैकएंड व डेटाबेस |
| `tt-payments` | प्रिया | पेमेंट व सुरक्षा |
| `tt-qa` | मोहित | QA टेस्टर |
| `tt-seotech` | इशिता | SEO व ट्रैकिंग |
| `tt-devops` | संदीप | डिप्लॉय व होस्टिंग |

## कैसे बुलाएँ
- नाम लेकर: "tt-inspector से मॉक टेस्ट 5 की जाँच करवाओ"
- या कहिए: "व्यापार टीम से इस हफ़्ते की प्राथमिकता निकालो" / "तकनीकी टीम से भुगतान-फ़्लो की समीक्षा करवाओ"
- व्यापार टीम: tt-manager, tt-inspector, tt-marketing, tt-selling, tt-performance
- तकनीकी टीम: tt-techlead, tt-frontend, tt-backend, tt-payments, tt-qa, tt-seotech, tt-devops

## सीमाएँ
- एजेंट सिर्फ़ पढ़ने/जाँचने के औज़ार लेते हैं; फ़ाइल बदलना, push, merge, deploy उनके हाथ में नहीं।
- हर एजेंट कीमत और टेस्ट-सूची `js/site-config.js` से लेता है, याददाश्त से नहीं।
